# 📚 本地知识库

**位置：** `D:\CODEX\kb`

这是给 AI 助手检索用的本地知识库目录。助手会直接在本目录内做全文搜索、按文件名查找、读取文档内容来回答问题。

## 如何使用

1. 把资料放进本目录（可建子目录分类，如 `技术文档/`、`项目资料/`、`笔记/`）
2. 对我说：「去知识库查一下 …」或「在 kb 里找 …」
3. 助手会自动用专用工具 `kb_search`（全文检索）/ `kb_read`（读文档）/ `kb_list`（浏览目录）搜索并引用原文回答，拿不准的会明确说明

> 知识库专用工具由动态插件 `kbtool-1` 提供，插件停止后工具随之消失；重新运行即可恢复。

## 资料格式要求

| 格式 | 是否支持 | 说明 |
|------|---------|------|
| Markdown (.md) | ✅ 推荐 | 最佳格式，直接可读 |
| 纯文本 (.txt) | ✅ | 可直接读 |
| JSON / CSV / 代码 | ✅ | 可直接读 |
| PDF (.pdf) | ⚠️ 需转换 | 先转成 .md 或 .txt 再放入 |
| Word (.docx) | ⚠️ 需转换 | 同上 |

## 推荐的文件写法

- **文件名**：短、含关键词，如 `ollama-安装指南.md`
- **开头元信息**：标题、标签（主题词）、来源、更新日期（可复制 `示例/资料模板.md` 使用）
- **正文**：用清晰的小标题分节，便于全文搜索时定位
- **内容**：保存原文，不要只存链接（链接失效就找不到了）

## 索引说明

本文件（README.md）就是目录索引。资料变多后，对我说「**更新知识库索引**」，助手会重新扫描全部文件，把索引更新为最新的目录清单。

## 固化说明（2025 之后）

- 知识库检索工具已固化为用户 preset **`kbagent`（知识库检索）**：`~/.dsh/.agent-presets/kbagent/`，内含 `kbtool.cjs` 插件，随预设自动挂载，重启不丢。
- **新开会话时请选择「知识库检索」preset**（而不是「创造模式」），即可使用 kb_search / kb_read / kb_list。
- 本会话当前运行的是 shipped `cordis` preset，其上的工具由动态插件 `kbtool-1` 提供，进程重启后消失；`kbagent` 预设没有这个问题。
- PDF 转换：放入本目录的 PDF 需先转成 .txt（输出到 `文档/` 子目录）才能被检索；转换脚本在 `%TEMP%\kb-pdf-extract\extract.mjs`。
