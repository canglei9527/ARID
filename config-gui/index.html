❓ 常见问题

如何填写 API key？

在规划/执行卡片里「API key」密码框输入即可（留空表示不修改）。保存时写入 ~/.dsh/.credentials.yaml，只会新增/变更对应键，绝不回显明文。若路由尚未有 apiKeyEnv，会自动生成（如 GATEWAY_API_KEY）。网关卡片里的 key 同理，写到该网关路由的 apiKeyEnv。

如何选择模型？

Provider 下拉列出所有已配置路由（含网关）。「Provider」选定后，模型名输入框会自动联想该路由的 models 列表（来自 settings.yaml），也可直接手输任意模型名。建议填该路由 base_url 实际支持的模型 id。

思考程度为什么不生效？

规划模型的思考程度写入 agent-default-model.reasoningEffort；DeepSeek 类适配器通常只接受 high/max， 其它值请按模型实际能力选择。执行模型的思考程度是 route 级的（子代理不支持 reasoningEffort），写到 llm-pi-ai.providers.<route>.reasoning。若执行与规划共用同一 route 且思考程度不同，本工具会自动派生独立 route <route>-exec 并把执行 provider 指向它，避免互相污染。

保存后什么时候生效？

需要重启 dsh web（关闭 start-arid.bat 打开的窗口后重新双击）或新建会话。执行模型是每次调用 subagent_executor 时实时读取的，理论上不需要重启，但为稳妥起见仍建议重启。

如何新建一个 OpenAI 兼容网关？

点「＋ 新建 OpenAI 兼容网关」，填入 route 名（如 molifang）、显示名、协议（openai-completions）、 baseURL（必须 http(s):// 开头）、models 列表（id + 可选 contextWindow），以及该网关的 API key。保存后它会出现在规划/执行下拉框中，即可选用。

llm-pi-ai:
  providers:
    molifang:
      displayName: 魔方网关
      apiKeyEnv: GATEWAY_API_KEY
      api: openai-completions
      baseURL: https://example.com/v1
      models:
        - id: gpt-5.6-sol
          contextWindow: 200000
dsh 还没安装怎么办？

先运行包内的 install.bat（会自动安装 Node 检查 + npm install -g @deepseek-ai/dsh）， 再运行 configure.bat 配置模型，最后双击 start-arid.bat 启动工作台。

端口 3456 被占用？

可用环境变量 ARID_GUI_PORT 指定其它端口（如 set ARID_GUI_PORT=4567 后再运行 configure.bat）。

如何卸载/重置？

删除 %USERPROFILE%\.dsh\.agent-presets\arid-dualmodel\ 目录；删除 settings.yaml 里的 agent-default-model、arid-dual-model、以及 llm-pi-ai.providers 下你自行添加的路由段。 凭据文件 .credentials.yaml 里对应键可一并删除。
